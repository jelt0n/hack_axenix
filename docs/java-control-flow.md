# Проверенное управление Java (#6)

Целевая среда корпуса — JDK 21, JavaParser 3.27.1. Отдельный технический документ
организаторов пока не получен. Полное покрытие обязательного перечня не заявляется;
неизвестные требования остаются открытыми до сверки с этим документом.

Граф показывает вход и выход, условия, операции, выбор `switch`, шаги циклов и
переходы `break`/`continue`/`return`. Обратные рёбра пунктирные и не участвуют в
расчёте вертикальных уровней. У каждой операции сохраняется диапазон исходника.
Связи строятся приложением; пользователь не соединяет произвольные блоки.

| Вариант | Обещание | Корпус |
| --- | --- | --- |
| `if/else`, вложенные ветки | Оба исхода и сохранение областей видимости | #5, `while`, `nested` |
| `while` | Условие до тела, `continue` к условию, `break` за цикл | `while` |
| `for` | Инициализация один раз, условие, тело, обновление; `continue` к обновлению | `for` |
| `for (;;)` | Нет выдуманного выхода по ложному условию; выход через `break` | `infinite_for` |
| `do/while` | Тело до первой проверки, `continue` к условию | `do` |
| `foreach` массива | Подготовка обхода, проверка наличия и получение элемента | `foreach_array` |
| `foreach` коллекции | Тот же порядок для `Iterable` | `foreach_list` |
| `switch` с двоеточиями | Выбор метки, проваливание, `default`, локальный `break` | `switch_colon` |
| Пустые/соседние метки | Метки могут вести к общему телу | `switch_empty_labels` |
| Стрелочные ветки с `{}` | Выход после ветки, без проваливания | `switch_arrow` |
| Вложенные циклы | `break`/`continue` относятся к ближайшему подходящему контексту | `nested` |
| `switch` внутри цикла | `break` завершает switch; `continue` продолжает внешний цикл | `switch_colon` |
| Ранний `return` | Переход к выходу метода, минуя обновление цикла | `return` |
| Тело без `{}` | При добавлении операции создаётся блок, исходная область не расширяется | `unbraced` |

Примеры находятся в [tests/fixtures/control_flow](../tests/fixtures/control_flow).
Файл `cases.json` задаёт известный stdout и сохраняющую поведение правку.
Каждый заявленный пример проходит импорт, экспорт и повторный импорт, правку
операции через HTTP API, генерацию Java, настоящий javac и изолированное выполнение
обеих версий. Ожидаемый вывод задан литералом, а не вычисляется из реализации графа.

Дополнительно HTTP-тесты проверяют отдельные связи переходов и отказ `break`/`continue`
вне допустимого контекста. Браузерный тест проверяет раскладку цикла, правку тела,
совпадение результатов, изменение условия и различие результатов новой ревизии.
Вставка, перемещение и удаление операции отдельно компилируются и выполняются
после каждого действия в теле `while` без скобок и ветке `switch` с двоеточием.
Эта проверка не означает полный перебор всех действий во всех сочетаниях конструкций.

## Правки и границы

Содержимое последовательностей, тел циклов и веток switch редактируется действиями
#5: замена, вставка, удаление, перемещение внутри одной последовательности. Условия
циклов и селектор switch редактируются выражением. Синтетические шаги и заголовки
инициализации/обновления `for`, переменная/источник `foreach` показываются для чтения;
для их изменения используется текстовый редактор. Перенос между областями видимости
отклоняется. Синтаксическая проверка не заменяет компиляцию и сравнение поведения.

Формы, которые пока сохраняются целиком с явным пояснением:

- `switch`-выражения со значением и `yield`;
- стрелочные ветки без блока `{}`;
- pattern matching и guards `when` в switch;
- помеченные инструкции и переходы по меткам;
- `try/catch/finally`, `synchronized` и прочие конструкции вне объёма #6.

Для непрозрачного блока ребро «При продолжении» обозначает только возможное
продолжение; внутренние переходы не изображаются как известные. Исходные токены
сохраняются. Эти формы не включаются в обещание полного структурного редактирования.

Открыто до технического документа: точный уровень языка, допустимые формы switch,
требование поддержки меток, полная комбинационная матрица конструкций и ограничения
стандартной библиотеки. Поддержка JavaParser сама по себе не означает проверенную
поддержку графом и редактором.
