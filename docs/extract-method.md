# Выделение фрагмента в метод

В разделе «Выделение метода» выберите первую и последнюю операции текущего метода
и имя нового метода. Диапазон непрерывен и относится к последовательности верхнего
уровня тела метода. Щелчок по отдельной операции графа выбирает её как начальный
фрагмент; диапазон можно расширить списками. Номера учитывают все операторы, включая
конструкции управления: неподдержанный выбранный фрагмент получает объяснение.

«Предпросмотр выделения» показывает параметры с типами, возвращаемый тип, выходную
переменную, исходный фрагмент, замену вызовом и полный новый метод. Отмена не меняет
проект. «Выделить и проверить» обновляет Java, граф и список методов одной ревизией,
затем запускает сравнение исходной и рабочей версий на сценариях панели проверки.
Новый метод можно выбрать в списке и исследовать его граф.

## Каталог поддержки

- Обычный класс без extends/implements. Выделяется фрагмент метода с телом, включая
  static-метод; конструкторы, интерфейсы, record, enum и анонимные классы отклоняются.
- Один или несколько последовательных ExpressionStmt в верхнем теле метода:
  объявления одной примитивной переменной с явным типом и инициализатором,
  присваивания, арифметика, сравнения, логика, условные выражения, приведения к
  примитивам и инкремент/декремент. Поддержаны boolean/char/byte/short/int/long/float/double.
- Входы — используемые параметры метода и ранее объявленные в том же верхнем теле
  локальные переменные с известным примитивным типом и инициализатором. Порядок входов
  определяется первым использованием. Поля и типы не выводятся предположениями.
- Выходов не более одного: изменяемая внешняя локальная переменная/параметр либо
  объявленная во фрагменте переменная, необходимая после него. В первом случае вызов
  присваивает результат прежней переменной; во втором создаёт исходную переменную
  с её примитивным типом. При отсутствии выходов создаётся void-метод.
- Метод private и сохраняет static исходного метода. Прямые конфликты имени, уже
  существующие вызовы с этим именем, имена методов Object, ключевые слова и yield отклоняются.

Учитывается [лимит дескриптора метода JVM](https://docs.oracle.com/javase/specs/jvms/se21/html/jvms-4.html#jvms-4.3.3):
не более 255 слотов с учётом this у instance-метода; long/double занимают два слота,
остальные примитивы — один. Превышение получает отказ до подтверждения.

## Объяснимые отказы

Несколько выходов, var, неизвестный или объектный тип, массивы, поля, вызовы методов,
создание объектов, лямбды, аннотации выбранных объявлений и неоднозначная инициализация
не поддержаны. Ветвления, циклы, try/catch/finally, return, throw, break и continue
в выбранной последовательности тоже отклоняются: перемещение управления и областей
видимости требует отдельного анализа. Выделение внутри вложенного блока пока не
предлагается. Причина показана до применения; проект остаётся прежним.

Локальные final-переменные на входе и final-результаты отклоняются: передача через
параметр или вызов может потерять статус константы компиляции, необходимый, например,
для сужающего присваивания в byte или метки case. Final-константы, целиком остающиеся
внутри фрагмента, сохраняются; final-параметры исходного метода допустимы на входе.

Это явный узкий каталог, а не полноценный Java Symbol Solver. Синтаксический разбор
не заменяет компилятор. Проверка сборки и поведения идёт только в Docker; ошибка
компиляции или различие не становятся подтверждением сохранения поведения.

## Сохранность и ревизии

Применяется точный патч выбранного диапазона и вставка нового метода перед закрытием
его класса. Остальные методы, комментарии и оформление вне этих мест сохраняются.
UTF-16, CR/CRLF и токены диапазонов сверяются перед патчем. Исходная версия неизменна.
Предпросмотр привязан к владельцу, ревизии, диапазону и имени. Изменение выбора или
кода отменяет актуальность предпросмотра; подтверждение заново вычисляет кандидат,
проверяет SHA-256 и атомарно сохраняет новую ревизию.

## API

- POST `/api/projects/{id}/transformations/extract-method/preview`:
  `{revision, methodId, startIndex, endIndex, methodName}`. Индексы с нуля,
  startIndex включён, endIndex исключён; диапазон относится к верхнему телу метода.
- POST `/api/projects/{id}/transformations/extract-method/apply`: те же поля и
  `previewHash` из предпросмотра. Возвращает проект с новым списком методов.
- Клиент создаёт обычную проверку `/checks` для новой ревизии. UI делает это
  автоматически; при отказе очереди код сохранён и доступен повторный запуск.
