# Матрица приёмки и ограничения

Источник требований — спецификация GitHub #1 и задачи #2–#12. Пользователь подтвердил,
что отдельный технический документ организаторов не ожидается. Приёмка опирается
на опубликованный объём проекта и конкретные исполняемые примеры. Непроверенные
варианты Java/API не объявляются поддержанными только потому, что их разбирает JavaParser.

## Что не обещается

- Полная Java: type/symbol resolution и статическое доказательство исключений не реализованы.
  Javac проверяет типы после структурной правки; синтаксически корректная правка может не компилироваться.
- try-with-resources, метки, pattern matching/guards, switch-выражения и стрелки без
  блока остаются явно непрозрачными, сохраняются целиком и не редактируются внутри.
- Граф исключений показывает возможные пути. У каждого finally отдельное состояние
  ожидающего перехода; это объяснено на графе и в матрице Java.
- Records/enums, generics, лямбды и Stream API не заявлены полным набором редактора.
  Разобранный исходник сохраняется; отдельные библиотечные примеры не означают весь API.
- Big O — верхняя оценка узкого набора с допущениями, без гарантии ускорения.
- Нет аккаунтов, совместного редактирования, многопоточного пользовательского пути,
  сетевых/файловых/временных API как проверенных возможностей. Изоляция применяется ко всем программам.
- Проверки запускаются в Docker с общим ядром хоста. Политики ресурсов измерены;
  публичные параметры и фактические результаты конкретного релиза находятся
  в [журнале приёмки](../deploy/VALIDATION.md).

## Как получить результаты своего запуска

```bash
BLUEPRINTS_DOCKER_BIN=docker .venv/bin/pytest -q --junitxml=.cache/pytest.xml
BLUEPRINTS_DOCKER_BIN=docker npm run test:e2e
npm run build
.venv/bin/ruff check backend tests scripts
.venv/bin/ruff format --check backend tests scripts
```

CI сохраняет JUnit, ошибки браузера, журнал Compose и проверенный архив релиза.
В отчёте различаются выполненные и пропущенные тесты: запуск без Docker не является
проверкой исполнения, а недоступность публичного адреса не засчитывается как успешное демо.
