# Java Blueprints

Веб-среда для исследования Java-программ через код и граф выбранного метода.

Первый этап ([issue #2](https://github.com/jelt0n/hack_axenix/issues/2)): импорт `.java`, список методов и конструкторов, граф последовательностей и `if/else`, переход от блока к строке кода, экспорт Java с сохранением комментариев и оформления, восстановление временного проекта после обновления страницы.

## Требования

- Python 3.12+ и [uv](https://docs.astral.sh/uv/getting-started/installation/).
- Node.js 22.12+ или 24 LTS, npm.
- JDK 17+ с модулем `jdk.compiler`; рекомендуем JDK 21+. Команда `java` должна быть в `PATH`.
- Linux для совместного запуска через скрипт разработки.

## Подготовка и запуск

```bash
python3 scripts/setup.py
python3 scripts/dev.py
```

Откройте **http://127.0.0.1:5173**. API и его интерактивное описание доступны на **http://127.0.0.1:8000/docs**.

Подготовка устанавливает зависимости по `uv.lock` и `package-lock.json`, загружает фиксированные JavaParser/Gson из Maven Central и тестовый Chromium. Контрольные суммы Java-зависимостей находятся в `java/dependencies.json`. После подготовки приложение работает без внешних API, шрифтов и модели ИИ.

Нажмите **«Открыть пример»** либо загрузите свой `.java` до 256 КБ. Выберите метод слева; нажатие на блок выделяет соответствующие строки. Кнопка **«Экспорт Java»** скачивает код, напечатанный JavaParser из AST. Исходная версия хранится отдельно.

Для отдельных процессов:

```bash
# Терминал 1
.venv/bin/uvicorn backend.app:create_app --factory --host 127.0.0.1 --port 8000

# Терминал 2
npm run dev
```

## Проверки

```bash
.venv/bin/pytest
.venv/bin/ruff check backend tests scripts
.venv/bin/ruff format --check backend tests scripts
npm run typecheck
npm run build
npm run test:e2e
```

API-тесты работают с настоящим JavaParser и временным SQLite-хранилищем. Браузерный тест запускает API и Vite, загружает реальный файл, переключает методы, проверяет выделение строки, восстановление проекта и содержимое скачанного файла.

На машине с ограничениями песочницы серверы, браузер и TestClient должны иметь разрешение на локальные сокеты и потоки. Для собственного запуска достаточно обычного пользовательского процесса.

## Архитектура

- `frontend/`: React, TypeScript, React Flow. Отображение методов, исходника и графа.
- `backend/`: FastAPI, API проектов, хранение в SQLite и запуск доверенного Java-модуля.
- `java/src/`: JavaParser разбирает исходник как данные, строит граф и использует `LexicalPreservingPrinter` для генерации Java.
- `tests/`: проверки публичного API и браузерный сценарий.

Java-модуль компилируется при первом импорте и повторно после изменения его исходника. JVM для разбора ограничена 128 МБ heap; одновременно выполняется один разбор. Загруженная Java-программа на этом этапе **не компилируется и не запускается**. Граф и экспорт не означают, что поведение программы проверено.

## API первого этапа

| Метод | Путь | Результат |
| --- | --- | --- |
| POST | `/api/projects` | Импорт JSON с `filename` и `source`, проект и cookie сессии |
| GET | `/api/projects/current` | Последний проект текущего посетителя |
| GET | `/api/projects/{project_id}` | Метаданные, методы, исходная и сгенерированная версии |
| GET | `/api/projects/{project_id}/methods/{method_id}/graph` | Узлы, связи, диапазоны исходника и пояснения |
| GET | `/api/projects/{project_id}/export` | Скачивание сгенерированного Java |
| GET | `/api/health` | Готовность HTTP API |

Чужая или отсутствующая сессия получает `404` для проекта, графа и экспорта. Cookie сессии — HttpOnly, SameSite=Strict; при HTTPS также Secure. Содержимое исходника не вставляется как HTML.

## Данные и ограничения

- Временные проекты сохраняются в `.data/projects.sqlite3`, срок доступа — 24 часа. Переменная `BLUEPRINTS_DATA_DIR` задаёт другой каталог. Истёкшие проекты удаляются при следующем импорте.
- Редактор кода и граф на первом этапе доступны для исследования, без структурных изменений. Редактирование — отдельные задачи #4 и #5.
- Внутренний поток циклов, `switch`, `try/catch` и других сложных конструкций пока не раскрыт: конструкция видна целым блоком с пояснением; её текст сохраняется в Java. Это не заявляется полным покрытием обязательной базы.
- Объявления методов без тела сохраняются и показываются в списке; для них нет графа выполнения.
- Проверка поведения, очередь изолированного выполнения, диагностика и преобразования пока не реализованы. Следующий этап — [issue #3](https://github.com/jelt0n/hack_axenix/issues/3).
- Версию JDK и полную матрицу Java scope нужно сверить с отдельным техническим документом организаторов, когда он появится.

## Сборка интерфейса

```bash
npm run build
.venv/bin/uvicorn backend.app:create_app --factory --host 127.0.0.1 --port 8000
```

После сборки FastAPI также обслуживает интерфейс на порту 8000. Публичное развёртывание и измерение ресурсов сервера входят в отдельную задачу #11.
